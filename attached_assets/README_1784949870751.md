# Area Business Miner

Separate Scrapling-powered Google Maps area crawler. Draw a circle, rectangle, or polygon and retain only businesses whose coordinates fall inside the selected boundary.

## Run

```powershell
.\.venv\Scripts\python .\maps_area_scraper\app.py
```

Open `http://127.0.0.1:5052`.

## Scale mode

- Up to 300,000 unique businesses per run
- Up to 100,000 persistent point/category tasks
- Up to 5,000 boundary grid points
- 159 built-in discovery categories plus custom categories
- Two-phase pipeline: collect listing URLs first, then detail each globally unique place once
- Existing leads are seeded as completed details during legacy job migration, so they are not re-scraped
- One to eight workers with one reusable Scrapling `DynamicSession` per worker
- Shared task-start rate limit and randomized detail delays
- SQLite WAL queue in `area_scale.db`
- Exact pending-task recovery after app or machine restart
- Per-run deduplication using Place ID, phone, website, or name/address
- Only the latest 50 businesses are sent to the live browser UI
- CSV and JSONL are streamed from SQLite without loading all records in memory
- Failed discovery tasks and failed business details can be requeued separately

## Recommended progression

1. Start with 1,000 tasks and 2 workers.
2. Benchmark unique businesses/hour and failure rate.
3. Increase to 10,000 tasks and 3-4 workers.
4. Use 50,000-100,000 tasks only after confirming the machine, disk, and network remain stable.

The target limit is storage/queue capacity, not a guarantee that Google Maps will expose that many unique businesses. Coverage depends on selected area, grid spacing, category catalog, duplicate rate, throttling, and the data Google returns.

The map uses Leaflet and OpenStreetMap tiles only for normal interactive viewing. City/PIN centering is resolved through a Scrapling-driven Google Maps page; no Google Maps API key is required.
